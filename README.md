# Google Apps Scripts Collection

This repository is a collection of Google Apps Scripts (GAS) projects.

Each script or project is maintained on its own Git branch. To find a specific script, check the repository branches.

- On GitHub: use the Branches dropdown to browse available branches.
- Locally (command line):

  ```bash
  git fetch --all
  git branch -a
  git checkout <branch-name>
  # or
  git switch <branch-name>
  ```
